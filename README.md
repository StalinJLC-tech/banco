# Simulador de Cajero Automático (ATM) - Componente Practico

Proyecto desarrollado para la asignatura de **Introducción a la Ingeniería de Software**, enfocado en aplicar los fundamentos del control de versiones distribuido mediante **Git y GitHub**.

## Descripción del Proyecto
Este repositorio contiene un algoritmo funcional desarrollado en **PSeInt** (`cajero_automatico.psc`) que simula las operaciones básicas de un cajero bancario con validación de PIN de seguridad de 5 dígitos, acompañado de la ficha web de nuestro equipo (`equipo.html`).

## Funcionalidades
* **Autenticación:** Validación de acceso mediante clave numérica (`12345`).
* **Consulta de saldo:** Visualización del monto disponible en cuenta.
* **Depósitos y retiros:** Operaciones matemáticas con validación de fondos suficientes.
